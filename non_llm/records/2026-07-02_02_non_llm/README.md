# 2026-07-02_02_non_llm

## Idea

Replace the conv encoder with **s**hift mix +
**g**lobal **p**ooling (**m**ean and max), **2** global rounds, which we call `sgpm2`. It is a conv-free encoder whose
higher sample efficiency clears the gate on a 950-iteration matched-anneal schedule:

- **Local mix**: pad the board once, gather each cell's 3×3 neighborhood as 9 concatenated
  slices, and mix channels with a single dense GEMM (`(N·100, 36) → 64`) — a 3×3 conv's
  receptive field, but as one tensor-core-friendly GEMM instead of conv kernels.
- **Global context**: mean- and max-pool the cell features over the board, project, and
  broadcast the result back to every cell; a second channel mix (`128 → 64`) fuses local +
  global.
- **Second global round**: pool the mixed features again (mean+max → 64) and append the vector
  to the flatten readout before the projection into the MinGRU core.

Pooled board-global context (how many boxes remain, whether any cell is unsolved) is nearly free
to compute and raises held-out accuracy per training step; that extra margin over the 0.70 gate
is what pays for the short schedule.
